# 微博关键词时间窗口爬虫

按关键词和时间窗口采集电脑版微博搜索结果，保存 JSONL，并可选导出九列 Excel。运行参数集中在 `config.py`，进度通过 `tqdm` 显示。程序不使用 TUI 或数据库。

## 准备

需要 Python 3.8 或更新版本，以及 `uv`。

1. 在 `config.py` 里设置关键词文件、日期、时间窗口和筛选参数。
2. 将 `关键词.txt` 改成自己的关键词列表，每行一个词。
3. 在项目根目录新建 `cookie.txt`，把电脑版 `weibo.com` 的登录 Cookie 放在第一行。ZIP 不包含 Cookie；Cookie 是登录凭证，不要外传。
4. 安装依赖并运行：

```bash
uv sync
uv run python spider.py
```

想先检查本地窗口和解析逻辑，可以运行：

```bash
uv run python spider.py --selftest
```

## 设置

所有运行参数都在 `config.py`，包括日期、时间窗口、请求间隔、翻页上限、搜索筛选和输出路径。`START_DATE`、`END_DATE` 留空时使用今天；`OUTPUT_FILE` 留空时自动写入 `data/weibo_<开始日期>_<结束日期>.jsonl`。`EXPORT_EXCEL = True` 控制是否额外生成 Excel。

时间窗口支持 `hour`、`day`、`week`、`month`、`half-year`、`year`，或正整数天数。`MAX_PAGES` 控制每个窗口的翻页上限；降低它能缩短运行时间，也可能少采集结果。

当前配置按需求设置为 2022-11-01 至 2026-07-10，全国搜索，包含原创和转发，并过滤正文不含关键词的结果。运行前可在 `config.py` 调整范围。转发正文会附上带 `[转发原文]` 标记的原帖内容，关键词匹配检查完整正文。`WEIBO_LIMIT_RESULT` 限制当前输出文件的去重总量，重跑时会计入已有记录。

## 输出和续跑

结果文件每行是一条微博 JSON。旁边的 `.done` 文件记录已完成窗口，`.status.jsonl` 记录窗口的完成、失败、中断、限量或截断状态。请保留这两个文件。重跑时会跳过较早的已完成窗口，并重新检查最近 `RECHECK_HOURS` 小时内的窗口；结果按微博 ID 去重。运行中断后，再次运行同一配置即可继续，已有微博不会重复写入。

HTTP 请求最多尝试 3 次。网络错误、超时、408 和 5xx 会在重试间隔冷却；403/418/429 优先遵守服务器的 `Retry-After`，没有该值时按 `COOLDOWN_SECONDS` 逐步延长冷却（默认两次重试前等待约 30 秒、60 秒）。登录失效和明确不可恢复的 4xx 会停止请求。详情、长文或属地补查的响应异常会让对应窗口保持未完成，下次运行重新检查，已保存微博按 ID 去重。接口正常响应但某个字段没提供（例如 IP 属地）会保存为空，不会把空字段当网络错误反复请求。

长文优先通过电脑版接口补全；未返回正文时再尝试移动版状态和长文接口。详情失败、长文补全失败或翻页达到上限时，窗口会保留为未完成；失败复查也会撤销该窗口原来的完成状态。宽窗口结果过多时会自动细分到小时。小时窗口仍达到上限时会记录截断，无法承诺搜索接口提供了全部历史帖子。属地补查仍未返回值时保持空白，不用用户资料地点代填。

启用 `EXPORT_EXCEL` 时，程序在项目根目录生成与 JSONL 同名的 `.xlsx` 工作簿，每个关键词单独一个 Sheet；单个关键词超过 Excel 行数上限时继续拆分 Sheet。工作簿包含发布年份、用户 ID、帖子 IP 属地、帖子附带的地理数据、微博 ID、发布时间、完整微博正文、点赞数、评论数九列。两类位置数据分开保存；接口未返回时对应单元格留空。地理数据在 JSONL 中保留为原始对象，在 Excel 中以 JSON 文本显示，不把坐标数组擅自拆分或转换。ID 按文本保存，时间显示到分钟。关闭 `EXPORT_EXCEL` 后只写 JSONL，不会删除之前生成的 Excel。正文超过单元格长度上限时会报错，完整原文继续保存在 JSONL，避免静默截断。

若仍有失败或截断窗口，保存结果后以退出码 1 结束；Ctrl+C 的退出码为 130。数量上限是主动限量，会正常结束。

改变关键词或搜索筛选口径时，使用新的 `OUTPUT_FILE`，避免旧结果与新口径混在一起。

## 测试

本地回归测试不需要 Cookie，也不访问网络：

```bash
uv run python -m unittest discover -s tests -v
```

真实采集验收需要有效 Cookie，会访问微博并消耗数分钟。它测试历史日期边界、关键词过滤、长文、转发、去重、续跑、故障恢复和 Excel 回读；结果独立写到 `data/tests/`：

```bash
uv run python tests/live_crawl.py
```
